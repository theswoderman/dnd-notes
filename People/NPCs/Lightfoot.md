# Lightfoot

**Race:** Pegasus, small, sized for a gnome
**Affiliation:** [[Torin Turen]]'s mount
**Status:** Alive

## Summary
[[Torin Turen]]'s pegasus. Small, the appropriate size for a gnome, which fits since [[Torin Turen|Torin]] is a gnome.

Torin rode out of [[The Bettermans Guild]]'s camp on Lightfoot before dawn, leaving behind a note and a pegasus feather. [[Falstad Firebeard]] scried on the pegasus to find him, which is how the party saw what Torin was doing in the [[Sage Thorn Forest|Sagethorn]].

See [[Torin's Flight into the Sagethorn]].

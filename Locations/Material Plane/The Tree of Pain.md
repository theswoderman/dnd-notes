# The Tree of Pain

**Region:** [[Sage Thorn Forest]], near [[The Abbey]]
**Disposition:** Unknown

## Summary
A landmark named by [[The Collector]]'s corpse as the way to find [[The Abbey]]: "you will find the abbey near the tree of pain." See [[Speak with Dead with the Collector]].

[[Thol]] cast find the path to steer the party toward it, which is what took them to the riverbank in [[The Frozen Riverbank]]. Nobody has reached it yet.

See [[Panrelta Loose Ends]] for open questions.

## Connections
- [[The Abbey]], what it marks
- [[The Collector]], named it
- [[Sage Thorn Forest]], where the party is looking for it
